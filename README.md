# book-pins

Pin images for Pinterest, served over GitHub Pages so Pinterest can fetch them.

    p/<book>/<YYYY-MM>/<book>-<template>-<nn>.png

Every image is 1000x1500 (2:3, Pinterest's own ratio).

These are marketing images built from published paperbacks: cropped, tilted, part-coloured
and composited. None of them is a clean printable page, and no book interior is in this
repository. The books are on Amazon; each pin links to its own title.

Generated by a build script in a private repository. Nothing here is edited by hand — the
next build overwrites it. The upload CSV, the build manifest and the
already-published ledger stay private and are not part of this repo.
